# Трекер привычек — Telegram Mini App

Личный трекер привычек внутри Telegram: отмечаешь привычки, смотришь серии и статистику, бот напоминает в нужное время.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Сама Mini App (HTML + CSS + JS, без сборки) |
| `bot.py` | Бот на aiogram 3: раздаёт `index.html`, принимает настройки напоминаний и присылает их |
| `requirements.txt` | Зависимости Python |

**Возможности приложения**
- Три типа привычек: да/нет, количество (8 стаканов, 20 страниц), отказ (дни без срыва)
- Расписание по дням недели, отметка прошедших дней через недельную ленту
- **Огонёк и заморозки как в Duolingo.** Выполнил все привычки за день, и огонёк 🔥 загорелся, серия выросла. Пропустил день: если есть заморозка 🧊, она сработает сама и сохранит серию. Если заморозок нет, серия сгорает. Новая заморозка выдаётся за каждые 7 дней серии, слотов: 1, с 5 уровня — 2, с 8 уровня — 3
- **XP и уровни.** +10 XP за привычку, +20 за закрытый день, ×1,5 при серии от 7 дней. Уровни с титулами и наградами: слоты заморозок, тема «Полночь». XP считается из истории отметок.
- **Лига.** Еженедельное соревнование по XP среди пользователей бота (неделя по Москве): 5 лиг, группы до 30 человек, топ-5 поднимаются, в группах от 10 человек последние 5 опускаются. Итоги бот присылает в понедельник.
- **Честная серия.** Отмечать привычки можно только в тот же день, прошлые дни доступны только для просмотра.
- По каждой привычке: текущая и лучшая серия, процент за 30 дней, тепловая карта за 18 недель, достижения
- Статистика: последние 7 дней, идеальные дни, успешность по дням недели
- Данные хранятся в **Telegram CloudStorage**, поэтому синхронизируются между устройствами и не требуют базы данных. Вне Telegram используется localStorage.
- Тема (светлая/тёмная) берётся из Telegram, есть вибрация и нативная кнопка «Назад»

## Как запустить

### 1. Создай бота
1. Напиши [@BotFather](https://t.me/BotFather) команду `/newbot`, придумай имя и username.
2. Сохрани токен вида `123456789:AA...`.

### 2. Залей проект на хостинг с HTTPS
Telegram открывает Mini App только по `https://`. Проще всего [Render](https://render.com):

1. Загрузи эти три файла в репозиторий на GitHub.
2. На Render: **New → Web Service**, выбери репозиторий.
3. Build command: `pip install -r requirements.txt`
4. Start command: `python bot.py`
5. В **Environment** добавь переменные:
   - `BOT_TOKEN` — токен из BotFather
   - `WEBAPP_URL` — адрес сервиса, который выдал Render, например `https://habit-tracker-xxxx.onrender.com/`
6. Нажми Deploy. В логах появится `web server on port ...`.

Готово: напиши боту `/start`, нажми «Открыть трекер». Кнопка «Трекер» также появится в меню слева от поля ввода.

### 3. (По желанию) Красивая ссылка
В BotFather: `/newapp` → выбери бота → укажи тот же `WEBAPP_URL`. Получишь ссылку вида `t.me/твой_бот/tracker`, которой можно делиться.

## Запуск локально

```bash
pip install -r requirements.txt
export BOT_TOKEN=123456:ABC...
export WEBAPP_URL=https://xxxx.ngrok-free.app/   # нужен https-туннель, например ngrok http 8080
python bot.py
```

Посмотреть интерфейс без Telegram можно, просто открыв `index.html` в браузере. Данные тогда сохранятся в браузере.

## Важно знать
- **Бесплатный Render «засыпает»** после ~15 минут без запросов, и тогда напоминания не придут. Для надёжных напоминаний подойдёт Railway, VPS или любой сервис, который работает постоянно.
- **База данных.** Если задана переменная `DATABASE_URL` (например, бесплатный [Neon](https://neon.tech)), бот хранит пользователей, статистику и настройки напоминаний в Postgres, и они переживают обновления. Без неё используется локальный `habits.db`, который на бесплатном Render обнуляется при каждом деплое. Сами привычки и отметки в любом случае лежат в облаке Telegram.
- Чтобы бесплатный Neon не тратил лимит вычислений, бот держит данные в памяти и обращается к базе только при событиях: открыли приложение, написали боту, ушло напоминание.
- **Статистика для владельца.** Команда `/stats`. Первый, кто её отправит, становится владельцем (или задай `ADMIN_ID` — свой Telegram ID). У остальных команда не работает.
- Если хочешь держать фронт отдельно (например, на GitHub Pages), впиши адрес бота в константу `API_BASE` в начале скрипта в `index.html`. CORS в боте уже включён.

## Как устроено

```
Telegram ──открывает──▶ index.html ──CloudStorage──▶ привычки и отметки (облако Telegram)
                            │
                            └──POST /api/sync (initData)──▶ bot.py ──▶ Postgres/SQLite: пользователи и напоминания
                                                              │
                                                              └── каждые 30 сек: пора напомнить? → сообщение
```

- Привычка хранится в ключе `h_<id>`, отметки за месяц в ключе `l_<id>_<ГГГГММ>`, поэтому лимиты CloudStorage (4 КБ на значение, 1024 ключа) не мешают годами.
- Бот проверяет подпись `initData`, так что чужие напоминания подделать нельзя.
- Если привычка уже отмечена сегодня, напоминание не приходит.
